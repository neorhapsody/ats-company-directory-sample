# ATS Company Directory — free 50-row sample

A free sample of the **ATS Company Directory**: companies mapped to the applicant tracking system (ATS) they hire through, with a direct link to their public job board and its JSON endpoint.

The full directory has **7,977 companies** (Greenhouse 3,867, Ashby 2,319, Lever 1,691, Workable 72, Recruitee 28) and 269,858 open jobs. Every board was checked live on 2026-10-24 (UTC).

**Get the full file:** https://fikrimarhan.gumroad.com/l/owdwne

## What's in each row

Company name, website domain (where confirmed), ATS platform, board slug, careers board URL, public JSON jobs endpoint, open-job count, remote-job count, top departments and locations, whether the board publishes structured salary ranges, and the date it was last verified.

No personal data: no recruiter names, emails or phone numbers, and no copied job descriptions.

## Sources and attribution

The list of company boards builds on the [LastRound AI hiring data](https://github.com/fyrosofttech/lastroundai-hiring-data) (license: https://creativecommons.org/licenses/by/4.0/) and Outscal OpenJobs (MIT). Every board was re-verified live against each ATS's public job API and enriched with counts, salary flags, domains, locations and departments.
